# 🏦 Bank Management System (Java GUI)

A modern, desktop-based Bank Management System built using Java Swing and Object-Oriented Programming (OOP) concepts. 

## 🌟 Key Features
- **Account Creation:** Instant account generation with unique Account Numbers.
- **Transactions:** Deposit and Withdrawal functionality with balance verification.
- **Real-Time Database View:** Live `JTable` UI updating all account details seamlessly.
- **Interactive GUI:** Built with Java Swing for an intuitive user experience.

## 🛠️ Tech Stack
- **Language:** Java
- **GUI Framework:** Java Swing (`JFrame`, `JTable`, `JOptionPane`)
- **Architecture:** OOP Principles (Encapsulation, Data abstraction)

## 🚀 How to Run
1. Clone this repository or download the `BankSystem.java` file.
2. Open the file in any Java IDE (Eclipse / VS Code / IntelliJ).
3. Run `BankSystem.java` as a Java Application.
